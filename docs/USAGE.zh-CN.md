# DigUp Plus 推荐用法

产品名：**DigUp Plus**（宣传站与对外称呼）。基于开源 DigUp 的增强分支；核心是**本机语义检索**。

## 建议姿势（按场景）

### 1. 日常：后台常开 + 快捷键搜索（推荐）

1. 安装并打开 DigUp Plus，完成模型下载与索引目录选择。  
2. 在设置中开启「登录时打开」，让服务驻留菜单栏。  
3. 关掉搜索窗口没关系；**不要退出应用**，否则索引与监听会停。  
4. 用设置里的搜索快捷键随时唤起面板，用自然语言描述内容即可。

适合：找文件、截图、文档、音视频片段。

### 2. 无界面：CLI／Skill（Agent 与脚本）

后台应用仍须在跑（或至少索引已建好且你接受不自动更新）。

```sh
# Skill / 脚本示例（路径以实际安装为准）
python3 scripts/digup.py doctor
python3 scripts/digup.py status
python3 scripts/digup.py search '记得的内容' --limit 5
```

适合：Agent、自动化、不想开 GUI 时查询同一份索引。

### 3. 微信消息与朋友圈（能力优先，可选）

1. Mac 上登录微信并同步需要的历史。  
2. 配置兼容的 wx 读取环境（安装微信 ≠ 完成接入）。  
3. 在应用「微信」页浏览／筛选／导出；或用 Skill 的 `wechat` 子命令。  

须知：非官方导出通道；可能联网拉取头像／朋友圈图；**不承诺不封号**。详见 `WECHAT.zh-CN.md`。

### 4. 导出聊天档案

在会话中选日期范围（或快捷范围：一周／两周／一月／半年），导出为**目录**：文本 + 可获取的图片，正文内图片有锚点对应资源。

## 不建议

- 退出应用后仍期待索引自动更新。  
- 把排序分数当成正确率或置信度百分比。  
- 对外宣传「原版 DigUp 装插件即可」或「保证永不封号」。  
- 未配置读取环境时宣称微信能力已就绪。
